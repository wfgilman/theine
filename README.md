# theine

A Caffeine-style in-memory cache for the BEAM, in pure Elixir. W-TinyLFU
admission, lossy striped read buffers, amortized maintenance in one process,
and single-flight async loading from an L2.

The name is a placeholder (theine is caffeine's other name). Rename freely.

- `specs/` is the source of truth for what to build. One topic per file.
  Start with `specs/00-overview.md`.
- `AGENTS.md` says how to build, test and benchmark in this repo.
- `IMPLEMENTATION_PLAN.md` is generated by the planning prompt and consumed by
  the build prompt. It is disposable; regenerate it when it drifts.
- `loop.sh` runs the Ralph loop: `./loop.sh plan` once, then `./loop.sh [n]`.
